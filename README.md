# TheSmokeFan-HalfLife-project - Week 1

This is a custom PCB designed to build a smart air cleaning system. The board connects an Arduino Nano, an MQ-135 smoke sensor, and a small DC cooling fan together.

The main goal of this circuit is to keep an eye on the air quality. When the sensor picks up cigarette smoke, the Arduino Nano automatically turns on the fan to blow the bad air away. This helps protect people around smokers from secondhand smoke.
